# 《奶娃图鉴》介绍片 · V2 制作方案

> 导演版方案。**未确认前不改任何源文件。**
> 目标：45–55 秒主版，让第一次接触该梗的人也能理解；提高 3 秒留存 / 完播 / 转发，引导收藏完整图鉴。

---

## 一、V1 审片诊断（带时间码）

| 时间码 | 问题 | 性质 |
|---|---|---|
| 0.0–3.5 | 只有日期 + 一个文件气泡，无任何奶蛙形象。**第一次看见奶蛙是 5.1 秒。** | 留存杀手 |
| 0.0–12.5 | 12.5 秒用于"聊天 + 封面"，占全片 15.6%，只产出 1 条信息（"有这么个东西"） | 结构浪费 |
| 5.1 | 标题出现。对短视频而言晚了 4 秒 | 留存杀手 |
| 13.0–16.5 | 四条课程说明横向堆叠，19–44px 不等的注释文字，手机缩到 8–13px，**只能当纹理** | 可读性 |
| 25.0–28.0 | "75" 数字滚动 3 秒，画面只有数字 | 静态字卡 |
| 28.0 | 标本墙出现。**观众要等 28 秒才第一次看见"很多奶蛙"**——而这才是本片唯一的产品卖点 | 致命 |
| 32.0–39.0 | 12 格网格定格 7 秒，无内容递进（V1 已加逐张红框补，但仍偏静） | 静态字卡 |
| 41.0–49.0 | 三条分类横条 + 定义文字，**全是"说"没有"看"** | 说 vs 看见 |
| 57.0–64.0 | 素材数字定格 7 秒 | 静态字卡 |
| 65.0–72.5 | 静态手机截图漂 7 秒，无任何操作 | 说 vs 看见 |
| 75.5–80.0 | 收尾定格 4 秒 | 节奏拖尾 |
| 全片 | 版面语言单一：**居中标题 + 居中卡片**，21 个镜头里 17 个同构 | 视觉疲劳 |
| 全片 | 旁白 8 句，**与画面大字重复 5 句**（V1 中段改过一轮仍未净） | 信息浪费 |
| 全片 | 旁白无字幕，**静音观看丢失全部叙事线** | 硬伤 |

**结论**：V1 是"把应用截图讲了一遍"，不是"让人看见这个东西有多离谱"。V2 的核心任务不是加内容，是**换叙事引擎**——从"介绍"改成"展示"。

---

## 二、V2 核心策略（一句话）

> **先让人被 75 只奶蛙砸到，再解释为什么会有人把它做成教材。**

顺序从 V1 的「背景→对象→功能」改成「反差→动机→证据→来历→验证」，因为短视频观众只为前者留下 3 秒。

---

## 三、逐秒分镜表（52 秒 / 30fps）

**全局约束**
- 画布 1080×1920；安全区左右 76px；**底部 1580–1760 固定留给字幕条**
- 字幕条：44px / 半透明纸色底 / 距底 160px，与画面大字不重叠
- 每屏**只表达一个结论**；注释文字不小于 40px，否则删除，不上屏
- 全片「奶蛙」为正文正名，书名用「奶娃图鉴」，并在 10.2s 显式说明一次

## 六、可验收标准

### 技术
- [ ] 时长 52.0 ± 0.3s
- [ ] 1080×1920 / 30fps / H.264 / AAC 48kHz
- [ ] 响度 -14 ± 0.5 LUFS；**True Peak ≤ -1.5 dBTP**（V1 是 -0.7，必须修）
- [ ] 无黑帧；无 >2.0s 的完全静止段（收尾 0.6s 除外）
- [ ] 段落边界全部落在 BPM 96 的小节线上（2.5s 整数倍）

### 内容
- [ ] 3.4s 内出现「75」+ ≥8 张奶蛙形象
- [ ] 每个数字能追到源文件具体位置（SPEC 编号 / 图号 / 页面区块）
- [ ] 「奶蛙 / 奶娃」用法符合「教材写作奶蛙，社群写作奶娃」，且 10.2s 有一次显式说明
- [ ] 「6 大类」与筛选项的表述一致（**写"6 类"或"7 个筛选项"，不写"7 类"**）
- [ ] 「考试」一词只出现在录屏段的画面里，不在旁白中
- [ ] 全片不出现"开源"（仓库与 LICENSE 未就绪前）
- [ ] 每条旁白都有字幕条；**关掉声音能完整看懂**

### 表达
- [ ] 每屏只表达一个结论
- [ ] 无小于 40px 的注释文字
- [ ] ≥3 处全屏特写 / 局部放大（避免"居中标题 + 居中卡片"连排）
- [ ] ≥8 秒的真实界面操作（非静态截图）
- [ ] 圈选类标注标注为"示意"，不冒充量化评级

### 传播
- [ ] 封面帧：标本墙 + 复习资料文件名 + 书名（三元素同框）
- [ ] 片尾有明确入口与行动指令
- [ ] 配套产出：75 枚完整图鉴速查长图（竖版，可收藏）
