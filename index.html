01 / 第一章 · 观察与辨认

此龙非彼蛙

教材第一章先做区分：官方奶龙是儿童向 IP，奶蛙是它长出的成年版本。两者不是同一个形象，也不共享同一套设定；混为一谈正是社群里「龙蛙相争」的主要来源。

图 1.3 / 奶龙的官方形象圆脑袋、大肚皮、圆眼睛，呆萌、会喷火（主要用于加热食物）。
图 1.4 / 奶蛙经典形象黄色皮肤、绿色凸眼、四肢末端渐变发黑、肚皮突出，能发出爽朗大笑。
识别判据：保留「眼睛」与「大笑」两大核心特征，且处在社群共同语境中。也有部分魔改即便保留了特征，因脱离社群共同语境，并不被视作奶蛙变体。 —《概论》第七章 /《奶蛙学基础教程》试卷第 28 题

02 / 第二章 · 分类法

什么才算一只奶蛙

第七章把变体分成三支。分类不看「像不像」，看两件事：形体保留了多少，以及谁在用、怎么用。

I / RESKIN
换皮奶蛙

仅皮肤、图标或封面发生变化，大部分形体特征保留下来。例：异色奶蛙、植奶、VIVO 奶蛙。

II / MORPH
异形奶蛙

丢失大量形体特征，但仍保留眼睛与大笑。例：奶蛋、奶狗、奶蝠、西格玛奶蛙。

III / CROSSOVER
客串角色

本身不是奶蛙，因颜色或抽象气质相近而联动，分主要与次要两级。

「这些『设定』没有官方文本，全部由二创作品互相引用、逐渐沉淀而成，教材只是替它们做了编目。」 — 本册研究者旁注

所以本册把 75 枚标本 按「本体 / 换皮 / 异形 / 客串 / 十二奶肖 / 奶字母」归档：本体 4 条是源流与参照，中间 33 条是变体与联动，末两组 38 条是补编的族群图版。每一条都能点开大图、标记已认识。
